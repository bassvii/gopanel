Проверено на версии gopanel: 0.1 (в разработке).
Дата последнего обновления: 2026-10-08.

## Как проверялось

Для каждого клиента:
1. Ссылка сгенерирована командой `GET /users/{id}/links?address=<IP>`.
2. Импортирована в клиент (вставкой URL или сканированием QR).
3. Проверено подключение (открытие `https://ifconfig.me`).
4. Результат записан в таблицу.

## Что тестировать в первую очередь

Минимальный набор для MVP:
1. **v2rayN** на Windows — самый популярный клиент.
2. **Hiddify** на Windows — современный, поддерживает много протоколов.
3. **v2rayNG** на Android — популярный мобильный.
4. **Streisand** на iOS — если есть доступ к iPhone.

## Форматы ссылок

gopanel генерирует:
- `vless://<uuid>@<host>:<port>?<params>#<remark>` — VLESS
- `vmess://<base64-json>` — VMess
- `trojan://<password>@<host>:<port>?<params>#<remark>` — Trojan
- `ss://<base64(method:password)>@<host>:<port>#<remark>` — Shadowsocks

## Известные ограничения

- **TUN-режим** в клиентах (v2rayN, sing-box) перехватывает трафик WSL
  и ломает TLS/DNS. Используйте системный прокси, не TUN.
- **VLESS+REALITY** требует, чтобы клиент поддерживал REALITY.
  Старые версии v2rayN (до 6.x) — не поддерживают.
- **Shadowsocks 2022** требует клиента с поддержкой `2022-blake3-aes-256-gcm`.
- **IPv6** — адрес должен быть в квадратных скобках: `@[2001:db8::1]:443`.
