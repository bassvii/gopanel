# Security Policy

## Reporting a vulnerability

**Не открывайте публичный issue для уязвимостей.** Это раскрывает
проблему до того, как её можно исправить.

Как сообщить:

1. **GitHub Security Advisory** (предпочтительно):
   откройте [https://github.com/bassvii/gopanel/security/advisories/new](https://github.com/bassvii/gopanel/security/advisories/new).

2. **Email** (если GitHub недоступен): `<insert address>`.

Опишите:

- версию (коммит / тег),
- шаги воспроизведения,
- ожидаемое и фактическое поведение,
- влияние (что может сделать атакующий),
- вашу среду (ОС, как установлено).

Ответ в течение 72 часов. Исправление — как только получится,
с вашим упоминанием в release notes (если хотите).

## Модель угроз

### Что защищено

- **Админка не видна снаружи.** Listener слушает `127.0.0.1`. Доступ — только через SSH-туннель (`ssh -L`) или локально.
- **Пароли.** argon2id (t=2, m=64 MiB), минимум 12 символов. Неудачные попытки ограничены по IP и по аккаунту.
- **2FA (TOTP).** Секреты шифруются AES-256-GCM ключом вне БД. Один код — одно использование (защита от replay). Отключение 2FA требует пароль и код.
- **Сессии.** Cookie HttpOnly, SameSite=Strict, CSRF на всех изменяющих запросах. Idle-таймаут 12 часов. Смена пароля отзывает все другие сессии.
- **Бэкап.** Скачивание требует пароль (защита от украденной сессии). TOTP-секреты в дампе зашифрованы.
- **Xray.** HandlerService (runtime API) отключён. Приватные адреса (`geoip:private`) блокируются в routing по умолчанию. При падении панели Xray останавливается через `Pdeathsig`.
- **Внешние загрузки.** Xray, GeoIP, GeoSite скачиваются по фиксированным тегам с проверкой SHA-256.
- **Аудит.** Все действия администратора пишутся в `audit_log` с IP (с учётом `X-Forwarded-For`, если `TrustedProxies` настроен).

### Что не защищено

- **Локальный пользователь ОС.** Панель доверяет пользователю, от которого работает. Если у него есть доступ к `~/gopanel-data/secret.key`, он может расшифровать TOTP-секреты.
- **Компрометация хоста.** Если атакующий получил root на сервере — панель не защитит.
- **Атаки на Xray-клиентов.** Панель не аудирует клиентский трафик.
- **DoS на панель.** IP-lockout можно обойти, меняя IP. Для защиты нужен внешний firewall / rate limiter на уровне прокси.
- **Подмена адреса сервера в ссылках.** Панель генерирует ссылки с адресом, который вводит админ. Если он ошибётся, клиенты пойдут не туда.

### Безопасность по умолчанию

- `listen = 127.0.0.1` — панель недоступна из сети.
- `TrustedProxies = []` — `X-Forwarded-For` игнорируется, IP берётся из `RemoteAddr`.
- `SecureCookies = false` — только для loopback (HTTPS не нужен). Включать, если панель за HTTPS-прокси.
- Публичный listener подписок **отключён**.
- `geoip:private` блокируется в routing по умолчанию.

## Supported versions

До первого релиза поддерживается только ветка `main`.

## Известные ограничения сканера

`govulncheck` иногда сообщает о **GO-2026-5932**
(`golang.org/x/crypto/openpgp` — unmaintained, unsafe by design).
Уязвимость находится в модуле `golang.org/x/crypto`, но gopanel
использует из него только `argon2`. Пакет `openpgp` в графе вызовов
не участвует и в бинарник не линкуется. Действий не требуется.

## Безопасность по умолчанию

- Пароль админа — минимум 12 символов.
- 2FA (TOTP) — рекомендуется, но не обязательна.
- Бэкап содержит хеши паролей и зашифрованные TOTP-секреты;
  скачивание требует ввода пароля.
- Публичный listener подписок выключен по умолчанию.
